## Contract deployers

| Network | Deployer of the seven Nayori contracts |
| --- | --- |
| Stacks mainnet | `SP2BM4WCNQM286PFHPGA1BG2YXER0PCG1PKQ5MF1X` |
| Stacks testnet | `ST3MRPNX0VNWYRSJ07PNTASE5BZ9K5XE57ARZ39DY` |

The SDK's `NayoriNextClient` and the CLI pick the right deployer from the network you set. On
testnet, fund your wallets with STX and sBTC from the testnet faucets.

## CAIP-2 identifiers

```text
Stacks mainnet: stacks:1
Stacks testnet: stacks:2147483648
```

Never infer network from an address alone. Fix the network in the client configuration and reject a
quote, challenge or transaction plan that names another network.

## Units

- STX amounts are expressed in micro-STX (`1 STX = 1,000,000 micro-STX`).
- sBTC amounts are expressed in satoshis.
- Escrow deadlines count Bitcoin blocks, about ten minutes each on average.
- USDCx uses six decimal places and its canonical SIP-010 asset identifier.
