## CAIP-2 identifiers

```text
Stacks mainnet: stacks:1
Stacks testnet: stacks:2147483648
```

Never infer network from an address alone. Fix the network in the client configuration and reject a
quote, challenge or transaction plan that names another network.

## Units

- STX amounts are expressed in micro-STX (`1 STX = 1,000,000 micro-STX`).
- sBTC amounts are expressed in satoshis.
- USDCx uses six decimal places and its canonical SIP-010 asset identifier.
