## Non-custodial rule

Leather or an enterprise signer approves every economic transaction. OAuth tokens authorize
service access only. The Web application, API, MCP tools and documentation never receive a seed
phrase or wallet private key.

## Systems of record

| Concern | System of record |
| --- | --- |
| Agent registration and job escrow | Stacks mainnet |
| Reputation updates | Stacks mainnet |
| OAuth agents, clients and grants | OAuth PostgreSQL |
| Quotes, replay reservations and delivery | Facilitator PostgreSQL |
| Public adoption evidence | Stacks/Hiro-derived snapshot |

See [payment safety](/security/payment-safety) for validation and replay controls.
