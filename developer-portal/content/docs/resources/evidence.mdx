Nayori exposes a human-readable dashboard and machine-readable snapshots derived from the canonical
mainnet contracts.

The dashboard separates raw on-chain totals from explicitly attested external adoption. Unknown
wallets remain unattested. If a complete chain snapshot is unavailable, the API reports
`unavailable` rather than publishing false zeroes.
