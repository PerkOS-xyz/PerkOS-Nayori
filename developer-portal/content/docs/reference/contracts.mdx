`reputation-registry-v3`, `agentic-commerce-v6` and `sbtc-commerce-v5` are deployed under the
mainnet deployer above and selected by current application source defaults. They provide a fixed 12 Bitcoin burn-block
evaluator window, an explainable evaluator decision, a 144-block appeal period with a separately
pinned authority, a separate timeout-paid state, retryable reputation synchronization, source/job
namespacing, per-job sBTC token pinning, two-step ownership and an atomic 98/2 evaluated settlement.

All reviewed sources match on-chain byte-for-byte. The v6/v5 deployments confirmed in blocks
`8978368` and `8978377`; initialization and allowlist transactions confirmed through block
`8978385`, and canonical state was revalidated after two additional Stacks blocks. Exact hashes are
`8eb55ecc…f40a7b2` for STX and `13256797…052f53` for sBTC. The signer-free verifier also checks
owner and pending roles, canonical sBTC, both reputation allowlists, 12/144 windows, separate
authority, treasury and 200 basis points.

The same source generation remains verifiable in isolated QA on testnet under
`ST16EWRC01S1SFWGBP63MW47VY8P3AYFA8VGEBGE5`. Its STX and official PoX-5 sBTC complete paths pass,
and the real-timeout job `u2` settled in state `u6` with zero escrow, one exact payout and no
completion, reputation or rating credit. The earlier immutable `agentic-commerce-v3` and
`sbtc-commerce-v2` contracts remain testnet-only at 144 blocks as historical evidence.

The prior `agentic-commerce-v5`/`sbtc-commerce-v4`, v4/v3 and earlier v2 contracts are preserved as
immutable historical release evidence. They are not defaults for new jobs. Internal deployment and
smoke actors are release evidence, not external adoption, non-team usage or revenue.

## Verification

The active STX `agentic-commerce-v6` / sBTC `sbtc-commerce-v5` generation is documented in
[earned service fees](/commerce/service-fees). Existing v5/v4 job readers must select those
historical contract names explicitly and preserve their original no-fee economics.

Clone the public repository and run the signer-free verifier:

```bash
git clone https://github.com/PerkOS-xyz/PerkOS-Nayori.git
cd PerkOS-Nayori
npm ci
npm run verify:mainnet
```

The verifier compares exact source hashes, owners and pending roles, canonical sBTC, authorized
reputation callers, 12/144 windows, appeal authority, treasury and 200 basis points. It requires
no wallet or deployer key and cannot broadcast.
