## Verification

Clone the public repository and run the signer-free verifier:

```bash
git clone https://github.com/PerkOS-xyz/PerkOS-Nayori.git
cd PerkOS-Nayori
npm ci
npm run verify:mainnet
```

The verifier compares source, exposed owners, canonical sBTC configuration and authorized
reputation callers. It requires no wallet or deployer key.
