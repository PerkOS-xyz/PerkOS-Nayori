## Endpoint groups

| Group | Examples | Access |
| --- | --- | --- |
| Service state | `/health`, `/ready`, `/supported` | Public |
| Agent discovery | `/.well-known/agent.json`, `/llms.txt`, `/x402.json` | Public |
| Paid resources | `/v1`, `/mpp/v1` | Public challenge; wallet payment |
| OAuth discovery | `/.well-known/oauth-*`, `/oauth/jwks.json` | Public metadata |
| MCP | `/.well-known/mcp/server-card.json`, `/mcp` | Metadata public; invocation scoped |
| Merchant quotes | `/v1/quotes` | Merchant bearer credential |

Credential-free `GET` operations link to their public origin. Protected, state-changing and
economic operations provide complete request examples without a generic browser proxy or
credential-forwarding playground.
