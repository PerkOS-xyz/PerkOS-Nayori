# Agent readiness standards research — 2026-08-27

## Baseline

Cloudflare's `isitagentready.com` scored `https://nayori.ai` at 27/100 (Level 1). robots.txt,
sitemap, Markdown negotiation and AI bot rules passed. The evaluator did not count Nayori's
existing custom agent manifest and reported eleven other checks.

## Standards selected for this increment

- RFC 8288/RFC 9727 Link headers and `/.well-known/api-catalog`:
  https://www.rfc-editor.org/rfc/rfc9727
- Agent Skills Discovery v0.2.0 with artifact SHA-256 digests:
  https://github.com/cloudflare/agent-skills-discovery-rfc
- Agentic Resource Discovery (ARD), currently a draft:
  https://github.com/ards-project/ard-spec
- WebMCP imperative, read-only tools with AbortSignal cleanup:
  https://webmachinelearning.github.io/webmcp/
- Content Signals policy:
  https://contentsignals.org/

The evaluator's published check instructions were also reviewed at
`https://isitagentready.com/.well-known/agent-skills/` for `link-headers`, `api-catalog`,
`content-signals`, `agent-skills`, `webmcp` and `ard`.

## Decisions

- Publish only resources and tools that are already usable.
- Use `ai-train=no, search=yes, ai-input=yes`: Nayori permits indexing and runtime agent use, but
  does not grant AI-training permission.
- Serve both the evaluator-compatible `/.well-known/ai-catalog.json` and the newer ARD
  `/.well-known/ard.json` path from the same truthful manifest.
- Support the current `document.modelContext.registerTool()` API and feature-detect the older
  navigator surface without shipping a polyfill.
- Keep OAuth/OIDC, OAuth Protected Resource, `auth.md`, MCP Server Card and DNS-AID for separate
  work backed by real services or infrastructure. Do not fabricate them for score optimization.
- Treat commerce detection as a later interoperability increment; do not return a false HTTP 402
  from the web application while the API remains quote-only.

## Preview result

The exact PR #72 preview was scanned in Chrome after CI and deployment completed. It scored
67/100, Level 4 (Agent-Integrated), up 40 points from the production baseline. Link headers,
Content Signals, API Catalog, Agent Skills, WebMCP and ARD all passed. The scanner found two
WebMCP tools through `navigator.modelContext` and validated all three ARD entries.

The five remaining recommendations were DNS-AID, OAuth/OIDC discovery, OAuth Protected Resource,
auth.md and an MCP Server Card. This confirms the selected boundary: another metadata-only web PR
cannot honestly reach 100. The next score increase requires DNS control and live identity/MCP
services.
